# SmithersBot Demo Brief

## Goal

Create a launch kit for SmithersBot using the README, this launch-inputs folder, and real screenshots/assets.

The launch kit should include:

- a polished local landing page for smithersbot.com
- launch strategy
- launch checklist
- launch posts in the operator’s voice
- README demo section update with placeholders or links as appropriate

Do not deploy.

Do not use secrets.

Do not invent fake product UI.

## Landing page purpose

The page should make people understand the product quickly:

SmithersBot lets you leave agents running without giving up control.

It should support the demo, not replace the README.

The README is the source of truth for product details.
